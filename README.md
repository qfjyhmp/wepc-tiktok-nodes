## IP 属性排带宽前面

TikTok 判断一个连接值不值得信任，第一道关卡是 IP 的属性，不是你的码率。机房 IP 在 Scamalytics、ipinfo 这类 IP 数据库里被标成“数据中心 / 代理”，平台一扫就知道这是台服务器；住宅 IP 来自真实的家庭宽带运营商，在同一个数据库里显示为普通住户，双 ISP 意味着这个 IP 同时归属两家当地运营商，可信号更强。这套判断跟你的内容质量没关系，IP 属性不对，视频发出去挂在个位数播放量是常态。

WePC 这批 TikTok 专线就是把这件事做在前面：官网在套餐名上直接标“原生家宽”“双 ISP 家宽”“原生 IP”，其中英国那款非家宽的入门款只有 AUD$10.90，页面明确写了“非家宽 IP”，这种标注本身比含糊的“原生”有用，至少你知道自己买的是什么。

第二道关卡是地区。TikTok 的流量分发跟账号登录 IP 的地区强相关，做美区账号就得用美国 IP，做越南市场就得用越南 IP。买一台配置很高但 IP 落在错误国家的机器，等于给自己加了一层不必要的阻力。

第三道关卡是纯净度。拿到机器第一件事是查这个 IP 有没有被滥用过，WePC 官网在 TikTok VPS 页顶部直接给了查询入口 pingip.cn，让人下单前后自己去看归属和标记情况。这个动作值得做，尤其你打算一次开几个号的时候。

## 2TB 双向流量在直播里能撑多久

WePC 官网在绝大多数套餐上标的是“双向流量”，这两个字直接影响你的成本。双向计费意味着上行推流和下行数据都计入额度，直播恰好是上行持续吃量的场景。

按推流码率粗算：1080p 直播常见码率在 4–6Mbps，一小时大约消耗 1.8–2.7GB；把码率压到 720p 的 2–3Mbps，一小时约 0.9–1.4GB。按双向计费的保守口径乘 2，2TB 额度在 1080p 下大约能撑 370–550 小时，在 720p 下能撑 700 小时以上。如果按另一套更宽的口径，把 20Mbps 当常态化上行，一小时就是 9GB，2TB 只够 220 小时左右。

两种算法的差别在码率假设。实际操作里，OBS 里设的码率是多少，上行就按多少走，把码率、每天直播时长、每月播几天乘一遍，比看“2TB 很大”这种印象靠谱。下单前也值得跟客服确认一句：这款套餐的超量处理方式是限速还是停机，超量后限到多少。官网对部分套餐写了超量限速，具体到你要买的那款，问清楚再付。

## 常见问题

**普通 VPS 能不能直接拿来开播？**

技术上能推流，问题出在 IP 属性上。普通 VPS 给的是机房 IP，在 IP 数据库里被标成数据中心，TikTok 对这类 IP 的信任度低，限流、直播间没推流都跟这个有关。要开播，至少选标了原生 IP 或家宽的款。

**一定要选目标市场当地的节点吗？**

要。账号的流量分发跟登录 IP 的地区强相关，做美区就用美国节点，做越南就用越南节点。IP 地区错了，配置再高也补不回来。

**IP 被封了怎么办？**

WePC 的价格页没有公开写换 IP 的收费标准和时效，这块我不能替它编。下单前开工单问清楚两件事：封了能不能换、多久能换、收不收费。这三问答不出来，就先只买一个月试。

**直播到底要多大带宽？**

两种口径都成立，看你问的是什么。推流码率层面，720p 用 10–20Mbps、1080p 用 20Mbps 以上就够编码器跑；线路余量层面，单人直播留 100Mbps、多人或高清留 200Mbps 更稳。前者是 OBS 里的设置值，后者是给线路抖动留的缓冲。WePC 这批套餐里 100Mbps 和 200Mbps 是主流，日本无需中转款只有 50Mbps，靠三网优化补稳定性，属于另一种解法。

**用澳元结算，怎么付？**

WePC 是澳洲主体，官网以澳元标价，支持支付宝、微信、信用卡和 PayPal。PayPal 只支持澳币结算且需要人工审核，急用就选支付宝。折成人民币的金额随汇率浮动，别按固定汇率去算预算。
